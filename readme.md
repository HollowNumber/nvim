# My Nvim Config

This repository contains my personal Neovim configuration files. This is my opinionated setup.


## Installation

To use this configuration, clone the repository into your Neovim configuration directory:

```bash
git clone github.com/HollowNumber/nvim.git ~/.config/nvim
```

Then, open Neovim and run the following command to install the plugins:

```vim
:PackerSync
```
